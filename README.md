# ÉLAN BEAUTY — демонстрационный сайт

Вымышленный салон красоты для портфолио «Ольга.Диджитал». Цены, адрес, телефон и мастера вымышленные.

## Файлы
index.html, style.css, script.js, interior.jpg, interior-m.jpg (первый экран, изображение создано ИИ), hero.jpg, green.jpg (фото с Pexels), emerald.jpg (изумрудный маникюр), workspace.jpg, workspace-m.jpg (рабочее место мастера) и process.jpg, process-m.jpg (процесс маникюра), interior-room.jpg, interior-room-m.jpg (зона ожидания), care-room.jpg, care-room-m.jpg (кабинет ухода), изображения созданы ИИ.

## Запуск
Откройте index.html двойным щелчком. Сборка не нужна.

## Публикация
Загрузите все файлы в корень статического хостинга (Tiiny, Netlify, GitHub Pages). Файл index.html должен лежать в корне, а не во вложенной папке.

## Форма
Форма демонстрационная: заявки никуда не уходят. Чтобы подключить отправку, замените обработчик в script.js на отправку через ваш сервис (например, Formspree) и обновите текст согласия.

## Фото
Замените hero.jpg и green.jpg своими или фото с Pexels, Pixabay, Unsplash (проверьте лицензию). Заглушки в галерее («Интерьер», «Кабинет ухода») замените на `<img>`.

## Перед публикацией
Проверьте навигацию, квиз, форму и вид на телефоне; уберите пометки «демо», если делаете реальный проект.

## Галерея
Все карточки галереи заполнены фотографиями. Чтобы заменить фото, положите новый файл с тем же именем (для вертикальных карточек пропорции 3:4, например 1200×1600 px) и версию для телефона с суффиксом -m (около 660 px по ширине). Изображения интерьера создавались ИИ: проверьте условия использования, прежде чем применять их в коммерческих проектах.
